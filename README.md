# ⚽ FootballIQ — Premium AI Football Analytics Platform

FootballIQ is a modern AI-powered football analytics platform built using Python, Streamlit, SQL, Plotly, and Machine Learning. The platform provides advanced football intelligence through interactive dashboards, tactical heatmaps, player analytics, club rankings, radar charts, and AI-based performance predictions.

Inspired by platforms like Sofascore, Opta, and StatsBomb, FootballIQ combines data analytics, visualization, and machine learning into a premium sports analytics experience.

## 🚀 Features

- ⚽ Top Goal Scorers Analytics
- 🎯 Assist Leaders Dashboard
- 🔍 Advanced Player Search
- 🏟 Club Rankings & Team Analysis
- 📊 Interactive Radar Charts
- 🔥 Tactical Heatmaps
- 🤖 AI Player Performance Predictions
- 📈 Interactive Plotly Visualizations
- 🌙 Premium Modern Dark UI
- 🧠 Machine Learning Integration

## 🛠 Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Scikit-learn
- MySQL
- Power BI
- Machine Learning

## 📌 Project Goal

The goal of FootballIQ is to simulate a real-world football intelligence platform capable of analyzing player and club performance while delivering modern interactive analytics experiences.
